# HLK-7628N 固件编译与发布流程

> 所属总览：[固件编译方案.md](../../../固件编译方案.md)


## 9.1 机型与产物

- 硬件：32MB Flash + 128MB RAM，单网口，板载 I2C 屏，可选 4G（Air780E）
- 目标：`ramips/mt76x8`，profile `hilink_hlk-7628n`
- 源码树：`~/openwrt-23.05.6-hlk7628`（首次运行由脚本从 `~/openwrt-23.05.6` rsync 出独立树，共用 `dl`）
- 产物：`openwrt-ramips-mt76x8-hilink_hlk-7628n-squashfs-sysupgrade.bin`
- OTA：清单 `fw/hilink_hlk-7628n.json`，board `hilink,hlk-7628n`

## 9.2 脚本自动处理的内容

`build-firmware-hlk7628.sh` 每次编译都会：

1. 同步包：`mmdvmhost` / `dmrgateway` / `mmdvm-dashboard` / `dmrstream` / `mmdvm-board-7628` / `air780e-monitor`
2. 写版本号：`files/etc/mmdvm/fw.version` ← 本机型目录 `devices/mt7628/VERSION`
3. 覆盖 DTS：`targets/mt7628/mt7628an_hilink_hlk-7628n.dts`（I2C、GPIO0-3、serial1、128MB 内存、console 移到 ttyS2）
4. 改 `base-files/etc/board.d/02_network`：单网口全部划为 LAN
5. 替换 `config_generate`：默认 LAN 改为 192.168.7.1
6. 生成 `.config` 并 `make defconfig`，然后编译

## 9.3 包与关键配置

```
CONFIG_PACKAGE_mmdvmhost=y
CONFIG_PACKAGE_dmrgateway=y
CONFIG_PACKAGE_mmdvm-dashboard=y
CONFIG_PACKAGE_dmrstream=y
CONFIG_PACKAGE_mmdvm-board-7628=y
CONFIG_PACKAGE_air780e-monitor=y
CONFIG_PACKAGE_kmod-i2c-mt7628=y
CONFIG_PACKAGE_zram-swap=y
```

32MB Flash 空间紧张，`zram-swap`、`kmod-lib-lzo/lz4` 用于压缩内存；新增包前先看镜像是否超过分区。

## 9.4 编译

整个机型目录同步到构建机后编译（目录含 `packages/`、`targets/`、`VERSION`、脚本）：

```powershell
tar -cf .tools\7628-dev.tar -C firmware-build\devices mt7628
.tools\pscp.exe -batch -pw <密码> -hostkey <构建机hostkey> .tools\7628-dev.tar xy@192.168.8.200:/tmp/7628-dev.tar
.tools\plink.exe -batch -ssh -pw <密码> -hostkey <构建机hostkey> xy@192.168.8.200 "mkdir -p ~/mmdvm-devices && tar -xf /tmp/7628-dev.tar -C ~/mmdvm-devices"
```

```sh
cd ~/mmdvm-devices/mt7628
setsid sh build-firmware-hlk7628.sh </dev/null >/tmp/7628-build.log 2>&1 &
```

## 9.5 注意事项

- **必须禁用 MIPS16**：mt76x8 与 mt7621 一样默认 `-mips16`，`dmrstream` 的 mbelib-neo 在 MIPS16 下会段错误。修复在 `packages/dmrstream/src/CMakeLists.txt`，改包后必须重新同步到构建机再编，否则实时语音仍会崩
- 串口 console 在 `ttyS2`，`ttyS0` 留给双工板
- 只有一个网口，升级后如果忘记把该口划为 LAN 会直接失去管理入口；不要手工改 `02_network` 后不重新编译
- 当前线上版本：**V0.660**（2026-11-22），10,289,957 字节，sha256 `09092196...`

## 9.6 发布三件套（编程器 / breed / OTA 同源固件）

固件发布时必须运行 [make-flash-images.ps1](make-flash-images.ps1)，从最新 `squashfs-sysupgrade.bin` 自动生成：

| 产物 | 内容 | 用途 |
|---|---|---|
| `…programmer-32MB.bin` | uboot(0x0,192K) + u-boot-env(0x30000,64K) + factory(0x40000,64K) + firmware(0x50000 起) 补 0xFF 至 32MB | 编程器全片直刷 |
| `…squashfs-sysupgrade.bin` | 原样固件 | OTA / sysupgrade / breed 直刷（三用同一文件，不带包装头） |
| `SHA256SUMS` | 上述文件校验 | 发布校验 |

flash 布局（DTS `mt7628an_hilink_hlk-7628n.dts`，实机 /proc/mtd 已核实）：flash 为 mx25l25635e 32MB SPI。

注意事项：

1. **factory 分区是本机校准数据（MAC/无线参数）**：programmer-32MB.bin 内嵌的是从 7628 实机备份的 factory 段（[flash-backup/](flash-backup/)），**只能刷回本机**；刷其他板子必须先备份该板自己的 factory 段再重跑脚本
2. breed 直刷固件 = sysupgrade.bin 原样（mt76x8 通用 uImage 格式，breed 按 firmware 分区 0x50000 接受）
3. uboot-env / factory 备份来自实机 `dd /dev/mtd{0,1,2}ro`，若重刷过引导或换板需重新备份
- V0.660 关键变更：仪表盘 livecfg 接口注册（`DASH_ENDPOINTS` 补 `livecfg`），整机 OTA 保留 5 个 mmdvm 配置文件，统一单源仪表盘源码；已发布双源（Gitee + GitHub），下载 sha 校验通过
- MIPS16 禁用已固化在 `packages/dmrstream/src/CMakeLists.txt`，不要回退；V0.660 内置禁用 MIPS16 的 dmrstream（历史 V0.630 的 md5 `baa8e9d80de3d821cb6341fe7ebe411d` 仅作旧版本参考，V0.660 以构建产物 SHA256SUMS 为准）
